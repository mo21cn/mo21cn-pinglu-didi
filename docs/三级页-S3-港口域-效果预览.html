03 · 本批次把「防超卖」讲清楚的三段论

答辩口径：稀缺资源型实体的核心纪律——申请不占、确认才锁、超量即拒。

环节动作口径页面呈现
① 申请POST /port/appts四条硬约束（verified / 载重吨 / 吃水 / 船型）逐条比对，任一不满足立即 409泊位页「预约前置校验链」卡
② 待确认状态 pending不占档期，防恶意占位；档期甘特只画 confirmed泊位页头卡提示 + 空态文案
③ 确认POST /port/appts/{id}/confirm对泊位行加锁（FOR UPDATE）→ 统计窗口内重叠 confirmed → ≥ 并发容量即 409预约页「确认前容量预检」算式 + 冲突预警
④ 撤销POST /port/appts/{id}/cancelpending / confirmed 均可撤，撤销即刻释放档期预约页留痕「未产生占用」
