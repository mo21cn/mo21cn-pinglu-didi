## 读表约定（合同 §11.2 / §11.3 的口径）

1. **三个事实必须分开**：`未在 DEMO-1` / `未测试` / `已实现` 是**三个独立事实**。
   不得因为某个 demo 子例通过就把原 AC 记为整体通过。
2. **「证据与候选 SHA」列现在一律为「未取证」**。理由：DEMO-1 还没有候选提交，
   合同 §13 明令 `No dates or acceptance results are prefilled as if execution had occurred.`
   本列**留空待填**，不预填、不推断。
3. **「剩余实现 / 剩余验证」是两种不同工作**：写「实现」表示代码还不存在；
   写「验证」表示代码在但判据未取证；写「实现+验证」表示两者都欠。
4. 负责方统一为 **开发方（实现） / HO（验收）**；需外部访问或非开发方动作的项单独标注。
