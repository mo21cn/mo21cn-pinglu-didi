## 1. 结论摘要（五个关键发现）

| # | 发现 | 影响 |
| --- | --- | --- |
| **F1** | **仓库没有数据库迁移机制** —— `backend/app/main.py` 用 `Base.metadata.create_all(bind=engine)` 建表，无 alembic、无 migrations 目录 | 直接命中 PRD 9.2 与规范六：**必须**在 R1 引入最小版本化迁移。这是 S1 的前置阻塞项 |
| **F2** | **仓库没有后台作业/worker 机制** —— 业务代码零命中 `BackgroundTasks` / `APScheduler` / `Celery` / `arq` | Agent 作业表 + worker 需从零建设（计划 3.4） |

| **F4** | **金额与幂等机制缺失** —— 业务代码零命中 `Decimal`、零命中幂等关键字 | 规范三要求金额 Decimal／定点精度、操作幂等，均需新建公共机制 |
| **F5** | **可复用资产充足** —— 模型网关（`modules/agent/llm.py` + `LLM_MOCK`）、认证（`utils/auth.js`）、请求封装（`utils/request.js`）、对话壳（`pages/assistant`）、占位页（`pages/preview`）、组件（`components/port-picker`） | 符合规范"复用而非复制两套基础设施"；前端**不顺带重写** |

## 6. 对《交付计划 v1.1》的影响（需回写）

1. **S1 任务顺序调整**：迁移机制从"落地"提升为**第一优先**，因为它阻塞所有模型变更；幂等与金额精度并入 S1 模型定标。
2. **权限改造范围上调**：`current_role` 被 8 个 router 直接使用，"组织成员 + 委托访问权"必须做成**叠加层**而非替换，否则 AC-01 基线回归必挂。v1.1 风险 R2 的概率应从"中"上调为"高"。
3. **第一张 PR 内容明确**：按规范末条建议，先做 `chore/ci` 工程规范补齐——`ruff format --check` 进 CI、PR 模板改写、新增 `AGENTS.md`、CODEOWNERS 明确审查人、补 CI 分组骨架。随后开始 `feature/ENT-001-assignment-core`。
4. **前端约束写入**：不顺带重写前端；新增页面必须过 `verify_miniapp` 路由可达门禁。
