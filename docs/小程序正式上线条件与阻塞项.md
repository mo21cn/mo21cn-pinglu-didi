**技术侧基本就绪，门槛全在"合规与资质"。**

## 1. 上线必要条件（按办理顺序）

### 1.1 主体与认证

| 项 | 要求 | 备注 |
| --- | --- | --- |
| 主体类型 | 企业（或个体工商户）主体；个人主体**禁止**商业变现与多数经营类目 | 本项目为平台经营，必须企业主体 |
| 微信认证 | 需营业执照、对公账户、法人扫脸；认证费 **300 元/年**（个体户 30 元/年） | 认证通过才能用支付、部分接口 |
| 账号信息 | 名称**唯一**、图标/简介/类目必须与**实际功能一致** | 类目不匹配是驳回主因 |

### 1.2 小程序备案（**硬门槛：先备案，才能发布**）

- 依据《互联网信息服务管理办法》等，**自 2023-09-01 起所有境内小程序必须先备案**；
  已上架未备案的会被逐步清退。
- 入口：微信公众平台 → **设置 → 小程序备案 → 去备案**（未上架的在首页有「去备案」入口）。
- 流程与周期：
  1. 填写**主体信息 / 主体负责人 / 小程序信息（Appid、名称、**服务内容标识 1–2 个**）/ 小程序负责人**；
  2. 小程序负责人**人脸核身**（白/浅色背景、免冠、不遮面）；
  3. **平台初审 1–2 个工作日**；
  4. **工信部短信核验**（号码 12381，须 **24 小时内**在 `beian.miit.gov.cn` 完成，
     超时会被自动驳回）；
  5. **通管局审核 1–20 个工作日**（常见 7–15 天）；
  6. 备案号下发 ⇒ **才能进入版本发布/提审**。
- 上线后备案号自动展示在小程序「更多资料页」，无需自行悬挂。
- ⚠️ 若要**自定义域名**（不用云调用），该域名须**单独 ICP 备案**且与小程序主体一致。
  **本项目走 `callContainer`，可免这一步**。

### 1.3 服务类目与行业资质（**本项目最大不确定项**）

《微信小程序资质文件列表》里与本业务直接相关的类目：

| 一级类目 | 二级/三级 | 所需资质（节选） |
| --- | --- | --- |
| **物流服务** | 货物运输 | 《道路运输经营许可证》（经营范围需含**网络货运**） |
| **交通服务** | 水运（船企） | 《水路运输许可证》 |
| **交通服务** | 水运（港口） | 《港口经营许可证》 |

若按**平台型信息撮合/承运**（多货主发布货源、多船东接单、平台撮合与结算）经营，
行业通行门槛是**"三证一认定"**：

1. **增值电信业务许可证（ICP / EDI）** —— 经营性互联网信息服务；
2. **网络安全等级保护备案（建议三级）** —— 公安网安部门；
3. **线上服务能力认定** —— 省级交通运输主管部门（含接入省级监测系统）；
4. **《道路运输经营许可证》**（经营范围：**网络货运承运平台经营**）—— 县级交通运输主管部门。

⛔ 未取得即开展网络货运承运经营，属**无证经营**（责令停止、没收违法所得并处罚款）。
**这一项决定上线形态**：若先以"船货撮合信息平台"形态上线，需与甲方确认可接受的类目与资质边界；
若宣称"承运"，则必须先办齐上述证照。

### 1.4 隐私与数据合规

| 项 | 要求 | 本项目现状 |
| --- | --- | --- |
| **《用户隐私保护指引》** | **2023-09-15 起强制**：凡涉及收集用户个人信息，**提审前必须**在
  公众平台「设置 → 服务内容声明 → 用户隐私保护指引」按**实际采集情况**逐项申报，否则**无法通过审核** | ⏳ **未配置** |
| 权限最小必要 | 位置/相册/相机/麦克风等**按需申请**；拒绝授权不得封禁基础功能；禁止启动即批量索权 | ⏳ 待核对交互 |
| 隐私政策入口 | 小程序内**显著位置固定可访问**（采集范围/用途/存储期限/共享规则） | ⏳ 待做 |
| 数据存储 | 境内收集境内存储；加密传输与存储；留存期限最短必要 | ✅ 后端为本项目自建（境内） |
| 用户权利 | 查询/更正/删除/**注销**；账号注销**不得设障碍**（禁止"联系客服"式变通） | ⛔ **缺失** |

### 1.5 内容与功能合规（审核口径）

- **内容安全**：UGC（会话消息、附件）与**模型生成内容**需具备审核/过滤能力
  （微信提供 `msgSecCheck` / `mediaCheckAsync` 等内容安全接口）；
  含 AIGC 能力还涉及《生成式人工智能服务管理暂行办法》。→ 本项目**未接**。
- **账号体系**：必须有可用的**退出与注销**功能（本项目有退出、**无注销**）。
- **功能完整**：禁止空白页、测试内容、未完成功能；**存量的"演示"字样数据会被当作测试内容**。
- **名称/图标/简介**与实际功能一致；不得使用绝对化用语、不得侵犯商标/著作权；
  素材（图片/字体）需有授权。

### 1.6 技术侧

| 项 | 要求 | 本项目现状 |
| --- | --- | --- |
| 服务器 | 可用微信云托管（云调用私有协议）或已备案的 HTTPS 域名 | ✅ 微信云托管 `prod-d0ga9bxi6e4226222` |
| 域名 | 若用自建域名：须 ICP 备案 + HTTPS + 后台配置三类域名 | ✅ 走 `callContainer`，**免域名备案** |
| 登录 | 真实 `wx.login` + `code2session`（或云托管注入 `x-wx-openid`） | ✅ 已实测 |
| 服务可用性 | 生产实例不应依赖「默认公网域名」（约 1 天有效）或单点手工开关 | ⚠️ 需清理一次性开关（当前已清空） |
| 支付 | 若收款：微信支付商户号 + 对应主体资质 | ⏳ 未接（当前为"不宣称资金到账"的样本） |

## 4. 建议的最短路径

1. **本周（甲方）**：确认经营形态 → 定类目 → 启动**小程序备案**（周期最长，先启动）。
2. **本周（我方）**：配置**隐私保护指引**（先按现有采集项申报，后续变更再更新）→ 提审前最容易被卡的一步。
3. **下一迭代（我方）**：**账号注销** + **内容安全**接入（二者都是代码项，可并行开工）。
4. **提审前（我方）**：处理**空壳页面与"演示"数据**（隐藏未开放入口 / 替换文案），跑一遍
   《甲方实操评审指南》的验收清单确认无空白页。
5. **资质办理（甲方）**：按所选类目办证；若按"网络货运"承办，需预留**数月**（ICP/EDI、
   等保三级测评、线上服务能力认定、道路运输经营许可证）。

> ⚠️ 顺序要点：**备案**与**资质**是外部流程（周期不可控），必须**先启动**；
> 隐私指引、注销、内容安全是内部代码/配置项，可与之并行。
