### 第 ③ 步：操作手册（体验版分发，共四步）

#### 1. 上传代码

微信开发者工具 → 右上角「**上传**」→ 填**版本号**（如 `0.6.0`）与**备注**（写清本次改了什么，便于后台回溯）。

- ⚠️ 上传前确认 `miniapp/config/env.js` 的 **`RUNTIME_PROFILE='demo'`**（仓库当前值）⇒ 体验版会走**云托管**（真实微信登录）。
- ⚠️ 顺带核对主包体积（微信上限 **2MB**；本项目图片资源已压至合计 **160KB**）。

#### 2. 在后台设为体验版

`mp.weixin.qq.com` → **版本管理** → 在「**开发版本**」列表找到刚上传的那条 → 右侧「**选为体验版**」→ 提交。
设置成功后会**弹出体验版二维码**（可下载保存）。

#### 3. 添加体验成员

**成员管理 → 体验成员 → 添加成员**（填对方**微信号**）→ 对方在微信里确认。
- ⚠️ **只有名单内的微信号**能扫码打开；其他人扫码会提示无权限 —— 这不是故障。
- ⚠️ 个人主体额度 **15 人**，请预先确认评审名单。

#### 4. 分发二维码

把体验版二维码发给评审人员，**微信扫码即可打开**（无需装开发者工具、无需域名、无需审核、无需等待）。

#### ⚠️ 换版流程（这是体验版最容易踩的坑）

| 环节 | 关键点 |
| --- | --- |
| 每次重新上传并设为体验版 | **旧二维码立即失效** ⇒ 必须**重新分发新码**给全部成员 |
| 成员看到的是旧内容 | 微信客户端有缓存：**长按小程序图标 → 删除 → 重新扫新码** |
| 上传后刚改的代码没生效 | 微信 CDN 同步有**几分钟延迟**；确认下载的是「体验版」栏里**最新的**二维码 |

## 1. 上线必要条件（按办理顺序）

| 项 | 要求 | 备注 |

### 1.2 小程序备案（**硬门槛：先备案，才能发布**）

- 依据《互联网信息服务管理办法》等，**自 2023-09-01 起所有境内小程序必须先备案**；
  已上架未备案的会被逐步清退。
- 入口：微信公众平台 → **设置 → 小程序备案 → 去备案**（未上架的在首页有「去备案」入口）。
- 流程与周期：
  1. 填写**主体信息 / 主体负责人 / 小程序信息（Appid、名称、**服务内容标识 1–2 个**）/ 小程序负责人**；
  2. 小程序负责人**人脸核身**（白/浅色背景、免冠、不遮面）；
  3. **平台初审 1–2 个工作日**；
  4. **工信部短信核验**（号码 12381，须 **24 小时内**在 `beian.miit.gov.cn` 完成，
     超时会被自动驳回）；
  5. **通管局审核 1–20 个工作日**（常见 7–15 天）；
  6. 备案号下发 ⇒ **才能进入版本发布/提审**。
- **✅ 本项目状态（2026-09-24）**：**已办并核实** —— 小程序备案号 **`桂ICP备2026021348号-1X`**
  （`-1X` 为小程序服务项标识），主体「莫伟」（个人），审核通过日期 **2026-09-16**；
  已在后台「备案与认证」栏实测确认。
- ℹ️ **备案号后缀速查**（判断"是不是这个小程序的备案"）：无后缀＝主体；`-n`＝网站；**`-nX`＝小程序**；`-nA`＝App。
  依据 YD/T 3565-2019 与工信部《关于调整非经营性互联网信息服务备案编号的通知》。
- 上线后备案号自动展示在小程序「更多资料页」，无需自行悬挂。
- ⚠️ 若要**自定义域名**（不用云调用），该域名须**单独 ICP 备案**且与小程序主体一致。
  **本项目走 `callContainer`，可免这一步**。
- ⚠️ **备案与主体绑定**：主体变更/换账号后，须**先注销原备案、用新主体重新提交**，
  且服务内容标识须与新主体经营范围相符，否则管局驳回（§0.2「移交说明」）。

### 1.3 服务类目与行业资质（**属甲方办理项**，本项目最大不确定项）

《微信小程序资质文件列表》里与本业务直接相关的类目：

| 一级类目 | 二级/三级 | 所需资质（节选） |
| --- | --- | --- |
| **物流服务** | 货物运输 | 《道路运输经营许可证》（经营范围需含**网络货运**） |
| **交通服务** | 水运（船企） | 《水路运输许可证》 |
| **交通服务** | 水运（港口） | 《港口经营许可证》 |

若按**平台型信息撮合/承运**（多货主发布货源、多船东接单、平台撮合与结算）经营，
行业通行门槛是**"三证一认定"**：

1. **增值电信业务许可证（ICP / EDI）** —— 经营性互联网信息服务；
2. **网络安全等级保护备案（建议三级）** —— 公安网安部门；
3. **线上服务能力认定** —— 省级交通运输主管部门（含接入省级监测系统）；
4. **《道路运输经营许可证》**（经营范围：**网络货运承运平台经营**）—— 县级交通运输主管部门。

⛔ 未取得即开展网络货运承运经营，属**无证经营**（责令停止、没收违法所得并处罚款）。
**这一项决定上线形态**：若先以"船货撮合信息平台"形态上线，需与甲方确认可接受的类目与资质边界；
若宣称"承运"，则必须先办齐上述证照。

### 1.5 内容与功能合规（审核口径）

- **内容安全**：UGC（会话消息、附件）与**模型生成内容**需具备审核/过滤能力
  （微信提供 `msgSecCheck` / `mediaCheckAsync` 等内容安全接口）；
  含 AIGC 能力还涉及《生成式人工智能服务管理暂行办法》。→ 本项目**未接**。
- **账号体系**：必须有可用的**退出与注销**功能（本项目有退出、**无注销**）。
- **功能完整**：禁止空白页、测试内容、未完成功能；**存量的"演示"字样数据会被当作测试内容**。
- **名称/图标/简介**与实际功能一致；不得使用绝对化用语、不得侵犯商标/著作权；
  素材（图片/字体）需有授权。
